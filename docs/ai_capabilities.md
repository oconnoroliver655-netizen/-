# AI 能力规划

## 1. 功能定位
- **词汇与语法讲解**：根据句子提供语法分析、词汇用法说明。
- **听力练习辅助**：生成逐句听写文本、关键点总结。
- **口语评分**：评估语音流利度、准确度、发音；给出纠错建议。
- **写作批改**：指出语法、词汇、结构问题，给出修改建议与范文对比。
- **学习计划优化**：根据用户表现调整学习节奏，推荐重点内容。

## 2. 技术路线
1. **第三方模型接入**
   - 选择国内合规供应商：阿里云通义千问、百度文心一言、讯飞星火等。
   - 通过 API 网关统一封装，便于切换与多模型编排。
   - 设置频率控制与缓存，降低成本。

2. **自研模型与算法**
   - 自建词汇记忆模型：基于遗忘曲线的 SRS 调度算法。
   - 写作评分模型：Fine-tune 大语言模型 + 教研标注数据。
   - 语音评分：结合声学特征与 ASR 结果，使用深度学习模型（如 Wav2Vec2）。

3. **AI 工作流编排**
   - 使用微服务（如 Temporal、Airflow）管理批改、评分等异步任务。
   - 支持多轮交互：用户 → 对话引擎 → 教研知识库 → 返回反馈。

## 3. 数据与知识库
- 建立考试知识图谱：题型、知识点、考纲要求、难度系数。
- 收集高质量范文、口语示例、听力材料，进行标注与分类。
- 数据治理：脱敏、去重、质量评估、版本控制。

## 4. 质量控制
- 引入人工审核机制：教研老师抽检 AI 批改结果。
- 建立反馈闭环：用户对 AI 结果打分，触发重新评估。
- 指标：准确率、用户满意度、处理延迟、成本。

## 5. 成本与性能
- 设定日预算和调用配额，业务高峰前预估需求。
- 对频繁请求结果进行缓存（如作文批改历史、词汇解释）。
- 对大段文本任务采用异步返回 + 通知机制。

## 6. 合规与隐私
- 不在第三方模型中上传敏感个人信息；匿名化处理。
- 保留调用日志，便于审计与追责。
- 遵循《生成式人工智能服务管理暂行办法》相关要求。

## 7. Roadmap
1. **阶段一**：接入第三方大模型，实现作文批改、学习建议。
2. **阶段二**：引入语音评分 SDK，联合大模型生成反馈。
3. **阶段三**：自研模型上线，降低成本，增强差异化能力。
4. **阶段四**：构建知识库问答与智能教练，提供多轮学习辅导。
