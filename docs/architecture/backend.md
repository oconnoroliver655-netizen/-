# 后端架构设计

## 1. 架构目标
- 支撑安卓、网页、后续 iOS 多端统一服务。
- 可水平扩展，满足峰值 10 万并发请求。
- 保证数据安全与合规，提供高可用基础设施。

## 2. 技术选型
| 模块 | 技术栈 | 说明 |
| --- | --- | --- |
| 应用框架 | **NestJS（TypeScript）** 或 **Spring Boot（Java）** | 前期建议 NestJS，开发效率高、生态丰富；如团队 Java 背景可选择 Spring Boot。 |
| API 协议 | REST + GraphQL（学习资源查询） | REST 负责账号、支付、考试管理；GraphQL 提升前端复杂查询效率。 |
| 数据库 | PostgreSQL | 处理关系数据（用户、课程、订单、成绩）。 |
| 缓存 | Redis | 存储会话、排行榜、热数据。 |
| 搜索 | OpenSearch/Elasticsearch | 支持题库、资料全文检索。 |
| 对象存储 | 阿里云 OSS/腾讯云 COS | 音频、视频、图片等静态资源。 |
| 消息队列 | RabbitMQ / RocketMQ | 异步任务（学习提醒、报表生成、推送通知）。 |
| AI 服务 | 调用国内合规大模型 API（如阿里通义、百度文心） | 批改、口语评测、学习建议；后续可自建模型推理服务。 |
| 监控 | Prometheus + Grafana、ELK | 指标监控与日志分析。 |

## 3. 服务拆分
1. **用户与身份服务**
   - 登录注册、第三方登录、权限管理、用户画像。
   - 支持手机号 + 验证码、微信登录、游客体验。

2. **学习资源服务**
   - 词汇、题库、课程、音视频素材管理。
   - 提供标签、难度、考试类型等多维度索引。

3. **学习计划与进度服务**
   - 生成学习路径、进度跟踪、提醒服务。
   - 存储学习行为数据（学习时长、正确率）。

4. **练习与模考服务**
   - 出题、计时、答题记录、阅卷、报告生成。
   - 与 AI 批改服务交互，获取评分与点评。

5. **AI 能力服务**
   - 封装第三方模型接口，提供统一调用。
   - 缓存常用结果，提供异步任务队列。

6. **支付与订单服务**
   - 会员订阅、课程购买、优惠券。
   - 支付回调处理、账单对账、电子发票。

7. **通知与运营服务**
   - App 推送、短信、邮件、站内信。
   - 活动配置、积分体系、排行榜。

8. **内容审核与管理后台**
   - 运营录入题库、审核 AI 批改结果。
   - 数据报表与可视化分析。

## 4. 数据模型概览
- **User**：基本信息、学习目标、会员状态。
- **ExamProfile**：考试类型、目标分数、考试日期。
- **LearningPlan**：阶段目标、任务列表、进度状态。
- **Resource**：词汇、文章、音频、题目等元数据。
- **PracticeSession**：练习记录、题目详情、得分。
- **AssessmentReport**：模考/测评结果、AI 反馈。
- **Order**：商品类型、支付渠道、状态。
- **Notification**：消息类型、发送渠道、状态。

## 5. API 设计原则
- RESTful 命名规范，使用 `/api/v1` 版本号。
- 统一响应结构 `{ code, message, data }`。
- 使用 JWT + 刷新令牌管理访问令牌，结合 Redis 黑名单。
- GraphQL 用于复杂查询（如多条件资源搜索、个性化推荐）。
- OpenAPI 规范生成接口文档，结合 Swagger UI。

## 6. 安全与合规
- 手机号/身份证等敏感信息加密存储。
- 权限控制：角色（用户、会员、教师、运营、管理员）。
- 数据访问审计日志，可追踪敏感操作。
- 防刷策略：验证码限流、行为风控。
- 完善的隐私政策与用户协议。

## 7. DevOps 流程
1. GitHub/GitLab 管理代码，使用 trunk-based 或 Gitflow。
2. CI：Lint、单元测试、集成测试、构建容器镜像。
3. CD：使用 Argo CD / GitOps 或者 Kubernetes 部署流水线。
4. 环境划分：本地开发 → 测试环境 → 预发布 → 生产。
5. 自动化监控与报警：Prometheus 指标 + Grafana 仪表盘 + 飞书/钉钉通知。

## 8. 可扩展性规划
- 微服务拆分可逐步推进，初期以模块化单体部署，后期按服务拆分。
- 使用 API 网关（Kong/Traefik）统一鉴权与流量控制。
- 引入数据仓库（ClickHouse）进行学习行为分析。
- 为国际化预留多语言支持（界面文本、题库内容）。
